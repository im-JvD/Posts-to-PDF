# WP Posts Export to PDF

افزونه‌ای ساده و کاربردی برای وردپرس که به شما امکان می‌دهد از **تمام نوشته‌های سایت** یک خروجی PDF تهیه کنید.  
این افزونه به صورت خودکار کتابخانه TCPDF را نصب می‌کند و تمام مراحل تولید فایل PDF را برای شما انجام می‌دهد.

---

## ✨ ویژگی‌ها

- استخراج تمام نوشته‌ها در یک فایل PDF  
- نمایش اطلاعات کامل هر نوشته:
  - عنوان نوشته
  - لینک نوشته
  - دسته‌بندی‌ها
  - تاریخ انتشار
- نصب و پیکربندی خودکار TCPDF (در صورت عدم وجود)
- امکان دانلود مستقیم فایل PDF از پیشخوان وردپرس
- طراحی سبک و سریع، بدون بار اضافی روی سرور

---

## 🔽 نصب

1. فایل ZIP افزونه را از این مخزن دانلود کنید.
2. به پیشخوان وردپرس → افزونه‌ها → افزودن بروید و فایل را آپلود کنید.
3. افزونه را فعال کنید.
4. پس از فعال‌سازی، منوی جدیدی با عنوان **Post to PDF** در پیشخوان اضافه می‌شود.

---

## 🚀 استفاده

1. وارد منوی **Post to PDF** در پیشخوان شوید.
2. روی دکمه «تولید PDF» کلیک کنید.
3. فایل PDF به صورت خودکار ساخته می‌شود و برای دانلود آماده خواهد بود
---

## ⚙️ توسعه‌دهندگان

- افزونه از ساختار OOP استفاده می‌کند.
- شامل اسکریپت نصب خودکار کتابخانه TCPDF.
- قابل توسعه برای افزودن فیلترهای دسته‌بندی، وضعیت نوشته و غیره.
